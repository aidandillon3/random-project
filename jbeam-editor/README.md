# JBeam Editor

A visual editor for BeamNG.drive vehicles. It shows the vehicle in 3D the way the
game builds it (same slots, variables and node offsets) and lets you click around
to move nodes, connect beams, add collision triangles, set weights, swap parts,
make new parts and upfits, and import 3D models, then writes your changes back
into the `.jbeam` files.

## Starting it

You need Python 3.8 or newer (from python.org or the Microsoft Store). Nothing
else to install.

1. Double-click **Start JBeam Editor.bat** (or run `python run.py`).
2. It opens in your browser at http://127.0.0.1:8765/. Keep the black window
   open while you work; closing it stops the editor.
3. The first time, check **Settings**: it looks for your BeamNG user folder
   (`%LOCALAPPDATA%\BeamNG\BeamNG.drive\current`) and the game folder by itself.

## What it does

- **Parts menu like the game's.** Pick a part for every slot and the vehicle
  rebuilds. Load any `.pc` config, change tuning sliders, and save your own config.
- **3D editing.** Select (click, Shift+click, box drag) and move nodes with the
  arrows; add nodes that connect themselves to what you had selected; join nodes
  with beams; make collision triangles; delete; mirror left and right sides.
- **Properties.** Weight, collision, self collision, friction, material and
  group for nodes; spring, damping, deform and break strength, type and bounds
  for beams; collision on/off and flip for triangles. Every other option is
  editable too.
- **Weights and stability.** Each node is checked against the stiffness and
  damping of its beams at the game's 2000 Hz physics step and coloured green,
  yellow or red. Auto-weight fixes unstable nodes or spreads a total mass so
  stiff areas get more weight.
- **New parts and upfits.** Copy an existing part (also from the game, into
  your own mod folder), start from a ready-made braced box, or start empty. Add
  slots to parts so upfits have somewhere to go.
- **3D model import.** `.obj`, `.glb`, `.gltf`, `.stl` and `.dae`. Place it on the
  vehicle, then make a part: the mesh is written as a `.dae` with a material, a
  braced node cage with collision is built around it, weights are set so it is
  stable, and it is attached to the nearest vehicle nodes or the ones you pick.
- **JBeam text.** Any part's text can be opened and edited directly.
- **Check and export.** Check runs a full checker over your mod; Export packs
  your mod folder into a zip.

Press **Help** in the editor for the mouse and keyboard controls.

## Safety

- Only files in your own mod folders (`mods\unpacked\...`, plus any extra
  folders you add in Settings) are ever changed. The game folder and zip mods
  are read only.
- Edits change just the rows you touched; the rest of the file keeps its layout
  and comments. Every file is parsed again before it is written.
- A copy of every file is saved in `data\backups\<mod>\<time>\` before it is
  changed.
- Settings, caches, backups and exports live in the `data` folder next to the
  editor.

## Notes

- After saving, press Ctrl+R in the game to reload the vehicle.
- Wheels generated by `pressureWheels` are drawn as simple cylinders; their
  nodes are not part of the mass total.
- The stability colours are a guide worked out from the official vehicles,
  not the game's own check.
