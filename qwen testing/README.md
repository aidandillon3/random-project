# Qwen Testing

A simple snake game built with HTML, CSS and vanilla JavaScript.

## How to play

Open `snake.html` in any web browser.

- **Move:** Arrow keys or WASD
- **Pause:** Space
- **Start / Play again:** Enter or the button

Eat the food to grow and score points. Avoid the walls and your own tail!
The game speeds up a little with each food you eat.
