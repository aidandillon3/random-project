## Snake

A browser snake game in a single file, `index.html`. Open it in any browser to play.

- Arrow keys or WASD to move, Space to pause
- On a phone, swipe or use the on-screen buttons

## Body Tracker

Webcam full-body tracking for VR (hip, knee and foot trackers for SteamVR or VRChat).
See [`body-tracker/README.md`](body-tracker/README.md) for setup and calibration.

## JBeam Editor

Make and change BeamNG.drive vehicles in its own window: a Garage for lift kits, wheels, tires,
engine and paint; a Vehicle Builder that makes a complete drivable vehicle from sliders; a Scrap
Mechanic importer that turns your creations into BeamNG vehicles; a 3D Model Workshop for parts;
and the game's parts menu, tuning and full node/beam editing with a stability check and a drop test.
See [`jbeam-editor/README.md`](jbeam-editor/README.md).

## Local Agent

A Claude-style AI helper that runs on your own PC with local models: it can edit files, run
commands, see the screen and use the mouse and keyboard, with an approval step for risky actions.
It also starts llama.cpp with fast settings for a 16 GB card.
See [`local-agent/README.md`](local-agent/README.md).
