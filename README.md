## Snake

A browser snake game in a single file, `index.html`. Open it in any browser to play.

- Arrow keys or WASD to move, Space to pause
- On a phone, swipe or use the on-screen buttons

## Body Tracker

See [`body-tracker/README.md`](body-tracker/README.md) for setup and calibration.
